Argus

Self-hosted face and object recognition — a clean HTTP API for other apps and a full human curation UI in one container. Enroll people by name, match them across photos, review uncertain matches, and keep everything on your LAN.

Guides

  • Getting started

    Docker quickstart, first-run setup, native Python run, GPU configuration.

  • Concepts

    Review queue, suggested people (face clustering), manual face tagging, object detection models, and environments.

  • API reference

    Every endpoint with curl examples — detect, enroll, identify, verify, test, bulk, webhooks, merge, reprocess, search, filtering, export and import.

  • Integrating

    Correlating your own records with external_ref, staying in sync via the change feed, and batch operations.

  • Settings

    Every live setting — face thresholds, GPU, image quality, crop padding, YOLO vocabulary — with defaults and descriptions.

  • Troubleshooting

    GPU not detected, CUDA library errors, face model not loading, macOS segfault.

  • Development

    Running tests, linting, and cutting a release.
